# YITEISM Transparent Asset Pack

This package contains ready-to-use website brand assets made from the
transparent YITEISM logo.

## Recommended placement
Copy everything into:

`assets/brand/`

## Main files
- `header/yiteism-header-logo.webp` → preferred website header logo
- `header/yiteism-header-logo.png` → PNG fallback
- `favicon/favicon.ico` → browser favicon
- `favicon/apple-touch-icon.png` → Apple devices
- `favicon/android-chrome-192x192.png`
- `favicon/android-chrome-512x512.png`
- `social/yiteism-og-image-1200x630.png` → social sharing image

## Notes
- Header logo and transparent icon files keep a transparent background.
- Social sharing image uses a navy background for better presentation.
